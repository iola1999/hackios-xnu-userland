# RGB8_444_2P 像素探针

`rgb8-444-2p.m` 和同名 Metal shader 使用相同输入核对 Apple 原生设备与 Annibale 驱动的 `_RB4` / Metal 542 读取行为。探针只创建独立 IOSurface、纹理和缓冲。

## 1. 输入契约与覆盖范围

23G90 RenderBox 的 `0x196a39c30` 分支创建两个相同宽高的平面，bytes-per-element 分别为 1 和 2；`0x196a9d5a4` 按 IOSurface 属性对齐行跨度和平面大小。macOS 27 / Apple M5 Ultra 原生清屏、CPU 读回和 shader 采样已确认 plane 0 为 G，plane 1 字节顺序为 B、R，组合纹理返回 `(R/255,G/255,B/255,1)`。23G90 的通道顺序仍需独立对照。

正确输入为 17×9 非均匀 RGB 图案，两个平面均为全尺寸。各平面采用不同 stride，并给 plane 0、plane 1 设置非零 offset；实际值由 `IOSurfaceAlignProperty` 计算并在创建后核对。R、G 随坐标变化，B 为 `255-R`，每个像素均可检测 B/R 交换。

同一个 compute shader 对每个像素执行 normalized nearest sample 与 integer read，写入两份 RGBA32Float 结果。sample 坐标位于像素中心。输出先填 NaN，每种操作分别检查 153 个像素，要求结果有限且各通道绝对误差不超过 0.0005。IOSurface 和纹理持有到命令完成后释放。

该探针覆盖读取、显式几何与按契约持有资源。线性过滤、shader 写入、render clear、混合、跨 pass 可见性、argument buffer 和实际系统 scene 未纳入本次验收。

## 2. 错误对照与返回值

- `--swap-br` 只交换输入数据的 B、R 字节，预期颜色不变。sample/read 各应检测 153 个失配像素。
- `--half-plane` 先确认正确几何可导入 542，再把 plane 1 元数据改为 9×5。stride、PlaneSize 和底层 allocation 均保留全尺寸容量，并初始化全部分配内存；只在缩小后的有效范围填像素。创建后核对实际几何，防止 IOSurface 修改参数使对照失效。原生拒绝该几何或命令完成后的像素失配均分别记录；该项只验证错误几何的敏感性。

| 返回值 | 含义 |
|---:|---|
| 0 | GPU 命令完成，全部像素符合预期 |
| 1 | GPU 命令完成，存在像素失配 |
| 2 | 环境、几何、编译、命令或输出写入错误 |
| 77 | 正确几何的 542 导入返回 nil，输出 `UNSUPPORTED` |
| 78 | 正确几何导入成功后，错误半尺寸几何在 surface 创建或纹理导入阶段被拒绝 |
| 124 | 30 秒执行截止时间到达，包括初始化、编译和 GPU 等待 |

错误对照的运行错误、超时和正常几何不支持均计为未完成。`--half-plane` 原生接受后返回 0 会使检查脚本失败。现有 A830 驱动尚未实现 542；设备上应独立记录 `UNSUPPORTED`，该结果不能通过像素验收。

## 3. 宿主构建与原生参考

在用户态仓库根目录执行，输出目录必须尚不存在：

```sh
python3 tools/air/rgb8-444-2p-check.py --work-dir out/rgb8-444-2p
```

脚本在独立目录保存输入副本、命令、日志、原始 float 输出和 SHA-256，编译 macOS 原生探针及 arm64e iOS 探针，并对 iOS 程序签名和验签。iOS shader 使用 `air64-apple-ios16.5.0` / Metal 3.0，可执行文件最低系统版本为 iOS 26.0。脚本运行原生正确输入、两组错误对照和输出失败分类检查；不修改共享构建树，也不操作设备。

原始输出按行优先排列，每像素依次为 sample RGBA 和 read RGBA，共 8 个 little-endian float32。完整结果在输出目录的 `validation.json`。

## 4. 后续设备验收

由设备负责人将 `iphoneos-probe` 和 `iphoneos.metallib` 分别放入 `/annibale/bin/rb4` 与 `/annibale/share/rb4.metallib`。探针在 iOS 将输出写入 `/dev/console`，指定驱动后查询实际 Mesa 后端并拒绝 softpipe/llvmpipe。

```sh
/annibale/bin/rb4 /annibale/share/rb4.metallib --driver /annibale/lib/libannibalemetal.dylib
/annibale/bin/rb4 /annibale/share/rb4.metallib --driver /annibale/lib/libannibalemetal.dylib --swap-br
/annibale/bin/rb4 /annibale/share/rb4.metallib --driver /annibale/lib/libannibalemetal.dylib --half-plane
```

三个命令分别运行，正确输入先通过后再评估错误对照。正确输入预期 `RESULT mode=normal pixels=153 sample_mismatches=0 read_mismatches=0`；通道交换预期两项失配均为 153。半尺寸对照需结合返回值和拒绝阶段或实际失配计数判断。可用 `--output FILE` 保存原始读回；父目录需预先存在。
